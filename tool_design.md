# Описание пяти Tool для LLM-агента

## 1. calculator (калькулятор)

- **Назначение:** Точно считает арифметику, чтобы не полагаться на «прикидку» модели.
- **Вход:** Выражение или числа и операция: 125000 * 0.17.
- **Выход:** Число: 21 250.
- **Ошибки:** Вернуть понятное сообщение (например, «деление на ноль» или «неверное выражение»). Агент переспрашивает пользователя, а не выдумывает ответ.
- **Ограничения (права):** Только вычисления, без доступа к файлам и сети; ограничить длину выражения.

## 2. search_in_document (поиск по документу)

- **Назначение:** Находит в документе нужный раздел или фрагмент по смыслу или ключевым словам.
- **Вход:** Файл (или его id) и запрос: «требования к системе».
- **Выход:** Название и текст найденного раздела, номер страницы.
- **Ошибки:** Если файл не открылся или раздела нет, вернуть «не найдено» или «файл недоступен». Агент сообщает об этом и предлагает уточнить запрос.
- **Ограничения (права):** Только чтение; доступ лишь к загруженным пользователем документам.

## 3. get_ticket_status (статус обращения)

- **Назначение:** Получает текущий статус обращения из системы, только чтение.
- **Вход:** Номер обращения: 5412.
- **Выход:** Статус, дата обновления, ответственный (например, «в работе»).
- **Ошибки:** Если номера нет или нет доступа, вернуть код и описание ошибки («обращение не найдено»). Агент просит проверить номер, статус не придумывает.
- **Ограничения (права):** Только чтение статусов; без доступа к остальной базе и без изменения данных.

## 4. process_documents (обработка документов)

- **Назначение:** Обрабатывает набор загруженных файлов (извлекает текст, делает выжимку и т.п.).
- **Вход:** Список из пяти файлов и тип обработки.
- **Выход:** Результат по каждому файлу и список успешных и неуспешных.
- **Ошибки:** Не останавливаться из-за одного плохого файла: обработать остальные, вернуть отчёт, какие не получились и почему. Агент покажет это пользователю.
- **Ограничения (права):** Лимит на число и размер файлов; только чтение и обработка, без удаления оригиналов.

## 5. check_calendar (проверка календаря)

- **Назначение:** Показывает свободные слоты у участников, только чтение.
- **Вход:** Участники, дата, длительность встречи.
- **Выход:** Список свободных временных интервалов.
- **Ошибки:** Если календарь недоступен или нет прав, вернуть ошибку доступа. Если слотов нет, вернуть пустой список. Агент предложит другой день.
- **Ограничения (права):** Только чтение свободного и занятого времени; без создания и удаления встреч.
